# Lekce 4 – Cyklus while

Výukové materiály pro PyLadies Praha (podzim 2026).

Naučíme program **opakovat, dokud něco platí** – i když předem nevíme, kolikrát.

## Jak na to

Procházej složky popořadě (01 → 03). V každé složce:

1. Otevři číslované soubory s výkladem (`01_…`, `02_…`) po pořadí, spusť je (tlačítko Run) a čti komentáře.
2. Pak si otevři `cviceni.py` a zkus úkoly vyřešit.
3. Když si nevíš rady, mrkni do `reseni/`.
4. Máš hotovo a zbývá čas? Pusť se do `cviceni_bonus.py` (pokud ve složce je).

## Struktura

```
01_cyklus_while/   cyklus while, počítadlo, ukončovací podmínka, break, nekonečný cyklus, continue
02_for_vs_while/   kdy použít for a kdy while
03_opakovani/      procvičení všeho dohromady (while, for i dřívější lekce)
```

V každé složce:

```
NN_nazev.py                číslovaný výklad se spustitelnými ukázkami
cviceni.py                 úkoly k procvičení
cviceni_bonus.py           bonusové úkoly pro rychlíky
reseni/cviceni.py          vzorové řešení
reseni/cviceni_bonus.py    řešení bonusů
```
